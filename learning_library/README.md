# Learning library

Place only books or learning materials that you are allowed to use here. The current prototype uses recommended reference links and original short explanations; it does not yet automatically parse uploaded books into lessons.

For each material we later integrate, record:
- title, author, edition and publisher;
- permitted use/license;
- chapter/section references used for each learning track;
- original exercises and project prompts derived from the concept;
- a rule not to reproduce full copyrighted chapters or long passages.

Recommended starting references are listed in the Learning Studio. The official *An Introduction to Statistical Learning* site offers free companion materials for the Python edition.
