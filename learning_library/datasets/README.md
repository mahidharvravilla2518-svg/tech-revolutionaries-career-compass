# Included learning datasets

The CSVs in this folder are **synthetic practice data** made for the Career Compass learning exercises. They do not describe real people, a real company, or the current job market. Do not use them as market evidence or make claims about real-world rates from them.

- `retail_sales_demo.csv`: fictional product-level sales records for Python, SQL, data analysis, forecasting, and communication exercises.
- `ab_test_demo.csv`: fictional randomized product experiment records for statistics practice.
- `security_alerts_demo.csv`: fictional defensive security alerts for safe triage exercises.
- `energy_demo.csv`: fictional energy indicator values for charting practice.

Each project brief links to an optional public-data next step. Check terms, license, definitions, and data quality before using external data.
